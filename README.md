# H Morais Lançamentos

App do celular (PWA) ligado ao Painel Financeiro H Morais.

- `config.js`: endereço da API do painel e ID do cliente do login Google. Não são segredos: quem entra é conferido no painel.
- `sw.js`: guarda o app no celular para abrir sem internet. A cada versão nova, troque o número em `VERSAO`.
- Nenhum e-mail, senha ou dado financeiro fica neste repositório.
